# 黄金评测集

团队提供 10 篇最近精读过的论文，每篇填写 `golden_set.example.jsonl` 的专家标签。
本例是空模板，不是已完成的黄金集，不包含编造的代表作或人工评分。

对每次 Prompt 更新，固定论文和原文缓存，盲评以下四项，各 0–5 分：

1. 事实准确性：有无把模型猜测、未展示实验或旧版本结果当论文事实。
2. 证据支撑：锚点与引用是否准确，结论是否真的由引用支持。
3. 局限具体性：能否解释本论文设置中的边界，而非泛泛要求更多数据。
4. 假设可证伪性：具体对照、度量和推翻条件是否能直接开始实验。

建议门槛：无严重事实错误、自动引用检查全通过、人工每项均分 >=4。门槛是建议，
需团队确认。自动 quote 检查不能替代逻辑支持判断。每次记录模型、prompt hash、
source kind、是否截断、输入/输出 Token 和专家评语，避免只看排版效果。
