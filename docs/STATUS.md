## 已完成

- 全云端运行：新加坡 Supabase PostgreSQL 17 / pgvector + Render 全栈应用 + GitHub Actions。
- 23 张业务表，6 份带校验和的不可变迁移；匿名与 authenticated 角色无私有 schema 访问权。
- 邮箱密码登录、密码设置、持久会话续期；保留一次性邮件登录、正确公开域名跳转和中文认证邮件。
- arXiv / HF / Semantic Scholar 抓取、v1 首次提交校验、版本/DOI/标题去重、持久 HTTP 缓存。
- HTML → LaTeX → PDF 全文获取；同时支持未压缩 LaTeX，保留引用锚点、截断与来源标记。
- 结构化解读、事实/推断/假设分区、引用原句检查、分级精读与跨成员共享缓存。
- 团队主线 + 个人兴趣 + 投票/认领反馈排序，约 20% 探索及实际比例记录。
- 论文库、讨论、认领、投票、Idea Backlog、每周 Reading List 下载。
- 邮箱邀请七天有效、撤销、成员角色调整、移出及最后一位管理员保护。
- 成员主动申请入组、撤回、管理员通过/拒绝、待处理数量提示；新团队默认不被发现，管理员可开启申请。
- 管理员可修改团队名称，校验空白和长度；保存后顶部与团队选择/申请入口更新名称。
- 团队日报共享版次，新入组成员按需补齐个人清单，不新增模型调用；已为三位当前成员补齐当日清单。
- 第三方 OpenAI 兼容接口支持自定义地址/模型、Chat Completions 或 Responses、独立费率和缓存指纹。
- 收藏、已读和私有笔记，按团队与账号隔离；知识库可筛选收藏/未读。
- 全局/团队 Token 预留与结算、未知用量状态保守处理；当前为每天 20M Token，已取消金额限额。
- 输入/输出/缓存用量统计；金额模式保留为可选预设，当前后台仅按 Token 管理。
- 后台服务接入状态和任务记录；个人日报支持 Resend 或直接 SMTP，默认不发送。
- 周报优先向量聚类，缺少向量时可按真实团队主题分组；页面明确标注方法。
- GitHub 手动 `sample` 对三篇已有论文进行有限相关性评分与解读，不抓取新候选或外部推送。
